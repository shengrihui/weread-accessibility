# 微信读书网页无障碍实验版

为微信读书网页版补充屏幕阅读器可读的正文文本层和键盘操作支持，主要面向 NVDA 用户。当前版本：**0.2.0（实验版）**。

## 安装与反馈

1. 在浏览器中安装 Tampermonkey（篡改猴）。
2. 点击[安装脚本](https://raw.githubusercontent.com/shengrihui/weread-accessibility/main/weread-accessibility.user.js)，在脚本管理器中确认安装。
3. 打开微信读书网页版的阅读页面并刷新，让脚本在正文绘制前运行。
4. 在 NVDA 浏览模式下按 H 或 2 跳转到“阅读正文”，按 D 跳转到正文区域。

遇到问题请在[问题反馈](https://github.com/shengrihui/weread-accessibility/issues)中描述浏览器、NVDA 版本、阅读模式及复现步骤。请勿附上账号密码或完整书籍正文。停用脚本并刷新即可恢复原网页。

## 功能与原理

安装文件：`weread-accessibility.user.js`。在已有的油猴（Tampermonkey）中新建脚本，用文件全部内容替换编辑器内容，保存后刷新微信读书阅读页。必须刷新：脚本需要在网页绘制正文前运行。停用脚本并刷新即可恢复。

本版从阅读区域 Canvas 的实际 `fillText` 绘制记录获取文字，不请求章节接口，不自行解密，不保存或上传正文。双栏文本对应两张实际画布；上下滚动模式保留已经绘制在章节画布上的文本，通过位置相同的段落节点支持 NVDA 浏览光标滚动。没有把每段做成 Tab 控件，也没有接管 NVDA 朗读。

已实现：正文文本层、重绘去重、画布清除后删除旧文字、目录和字体选择键盘激活、工具栏名称、字体选中状态、目录搜索名称、弹层初始焦点及关闭后返回焦点。

0.2.0：按实际行距推断段落，修复常见的逐行拆段；同一阅读画布容器只标记一个正文区域，开头增加屏幕阅读器可用的二级标题“阅读正文”，没有新增按钮或链接。浏览模式下按 H 或 2 跳转标题，按 D 跳转区域。原网页的双栏页眉章名不再重复进入无障碍树。字号采用一个有当前值的滑块，方向键调整、Home/End 到最小/最大值，使用网页原生点击处理更新设置，避免误把滑块圆点当第八档。

“可点击”尚未消除：网页将点击处理绑定到正文祖先，滚动模式甚至绑定到 HTML 根节点。此版保留这些事件，避免破坏选词、划线和工具栏关闭行为；并不声称已经解决 NVDA 的“可点击”提示。

## 实际验证

1. 双栏刷新后，用 NVDA 浏览模式读正文，核对左右两页顺序；翻页后检查旧页不残留。测试章节交界处同屏两章。
2. 切到“上下滚动阅读”，用 Ctrl+下箭头逐段移动，再用 NVDA 连续朗读。检查页面是否跟随、是否漏读或重复；切回双栏核对边界。
3. 改字号、字体、窗口大小，再检查文本和视觉页边界。留意文字是否拼接错序。
4. Tab 到字体按钮并打开，检查焦点进入选项，Enter/空格切换、选中状态、Escape 关闭和焦点返回。检查目录搜索、章节切换、主题、想法按钮及登录弹窗。
5. 记录浏览器/NVDA 版本、模式、章节、操作和读出的错误内容。付费遮罩、图像文字、笔记和书友想法中的复杂交互需另外核验。

## 当前限制

0.1.0 已由用户验证双栏可读且翻页后对应显示内容、上下滚动模式可读且可跳下一章。0.2.0 尚未经真实 NVDA 验收。段落依据行距和缩进重建，仍不能保证诗歌、居中标题、无缩进段落及跨画布段落恢复准确。离屏画布绘制或位图复制、虚拟化回收画布仍需现场验证。自动连续朗读跨页或跨章不在已确认的验证结果中。

本地检查：`node --check weread-accessibility.user.js` 和 `node test.cjs`。这些只验证语法和布局算法，不证明浏览器注入成功、无障碍树正确或 NVDA 真正可读。
